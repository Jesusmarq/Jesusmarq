## Development philosophy

```text
Understand the problem
        ↓
Design a simple solution
        ↓
Build
        ↓
Test
        ↓
Improve
        ↓
Ship
        ↓
Maintain
```

I prefer learning by building real things, breaking them, understanding why they broke and improving them.
